🏦 PyBank – Banking Management System

📌 Project Overview

PyBank is a Python and MySQL-based Banking Management System that allows users to perform basic banking operations securely and efficiently.

✨ Features

- Create a new bank account
- Secure user authentication
- Deposit money
- Withdraw money
- Check account balance
- View transaction history
- Generate account summary

🛠️ Technologies Used

- Python
- MySQL
- SQL
- Git
- GitHub

📂 Project Structure

- banking/ – Contains banking modules
- main.py – Main application file
- requirements.txt – Required Python packages
- .gitignore – Excludes unnecessary files

⚙️ Installation and Execution

1. Clone this repository.

2. Install dependencies:
   
   "pip install -r requirements.txt"

3. Configure your MySQL database.

4. Run the application:
   
   "python main.py"
